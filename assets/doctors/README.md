# Фото докторов

Файл кладётся сюда с именем, равным идентификатору доктора из админки:

```
assets/doctors/<id>.jpg      например assets/doctors/harlamov.jpg
```

Нет файла — рисуется градиентный аватар с инициалами, страница не ломается.

## Требования

- **JPEG**, квадрат, **600×600**
- Размер файла — до ~100 КБ
- **Без EXIF**

## Как подготовить (macOS, без установки чего-либо)

```bash
# 1. Обрезать в квадрат по центру, ужать до 600×600 и снять метаданные
sips -s format jpeg -Z 600 --cropToHeightWidth 600 600 исходник.jpg \
     --out assets/doctors/<id>.jpg

# 2. Проверить, что EXIF не осталось
mdls -name kMDItemLatitude -name kMDItemAcquisitionModel assets/doctors/<id>.jpg
```

## Зачем это важно

**Репозиторий публичный.** Фото прямо с телефона несёт в EXIF GPS-координаты места
съёмки, модель устройства и дату — всё это уходит в открытый доступ и остаётся
в истории git навсегда.

Плюс исходник с iPhone весит 3+ МБ при 4000 px по стороне. Участники открывают
лендинг с мобильного интернета в зале, где связь и так перегружена: четыре таких
фото — это 12 МБ на загрузку страницы вместо 300 КБ.

Один раз такой файл уже попадал в историю и вычищался через `filter-branch`.
Сделать это дёшево можно только до первого `push` — дальше сильно дороже.
