# 30 — Дизайн-система

Реализация: [`assets/styles.css`](../assets/styles.css). Все токены — в блоке `:root` в начале файла.

**Правило: ни одного цвета, радиуса или размера хардкодом в компонентах.** Визуал будет
меняться по ходу — перекраска должна быть правкой одного блока, а не поиском по трём HTML.

---

## Идентичность

Источник — `sddday_logo.png`: тёмно-синий круг, градиент cyan → blue → violet, белая типографика.

**Тема тёмная.** Это осознанное отличие от прошлого лендинга (`change-agenda`), который был
светлым и сберовско-зелёным. Здесь бренд другой.

## Токены

```css
:root {
  /* Поверхности */
  --bg:        #070C16;   /* фон страницы */
  --surface:   #101827;   /* карточки */
  --surface-2: #162033;   /* вложенные блоки, чипы */
  --line:      #1E2A3E;   /* границы */

  /* Акценты */
  --cyan:   #22D3EE;
  --blue:   #2E7BF6;
  --violet: #8B5CF6;
  --grad:   linear-gradient(135deg, var(--cyan), var(--blue) 55%, var(--violet));

  /* Текст */
  --ink:    #E8EEF7;
  --muted:  #8A9AB4;
  --faint:  #56637A;

  /* Статусы */
  --ok:     #22C55E;   /* свободно */
  --busy:   #F59E0B;   /* мало мест */
  --off:    #64748B;   /* недоступно */
  --err:    #F43F5E;

  /* Метрика */
  --r-sm: 10px;  --r-md: 14px;  --r-lg: 20px;
  --gap:  16px;
  --shadow: 0 1px 2px rgba(0,0,0,.4), 0 12px 32px rgba(0,0,0,.28);
  --glow:   0 0 0 1px rgba(34,211,238,.35), 0 8px 28px rgba(46,123,246,.22);
}
```

Шрифт — системный стек (как в `change-agenda`): никаких внешних загрузок,
мгновенный рендер на телефоне при плохой связи.

## Компоненты

### Карточка доктора
Поверхность `--surface`, радиус `--r-lg`, граница `--line`. Слева квадратное фото 88×88
с радиусом `--r-md`. Справа: имя (700), роль (`--muted`, 13px), специализация чипом с градиентной
рамкой, био (`--muted`, 14px, максимум 3 строки с `line-clamp`), внизу «Стол №N» и бейдж занятости.

Наведение и фокус — подъём на 2px и `--glow`. Карточка без мест: `opacity: .5`,
`pointer-events: none`, бейдж серый.

### Аватар-плейсхолдер
Если `assets/doctors/<id>.jpg` не загрузился — `onerror` подставляет div с `--grad`
и инициалами (первые буквы имени и фамилии) белым, 28px, 700.

### Бейдж занятости
Пилюля 12px, 700, uppercase.

| Свободно | Цвет | Текст |
|---|---|---|
| ≥ 3 | `--ok` | `Свободно N из M` |
| 1–2 | `--busy` | `Остался 1 слот` / `Осталось 2 слота` |
| 0 | `--off` | `Мест нет` |

### Чип слота
Кнопка, минимальная высота **44px** (палец), радиус `--r-sm`, моноширинное время.

| Состояние | Вид |
|---|---|
| `free` | фон `--surface-2`, граница `--line`, при наведении градиентная рамка |
| `taken` | фон прозрачный, текст `--faint`, зачёркнут, не кликается |
| `blocked` | как `taken`, но подпись «недоступно» |
| `past` | `opacity: .25`, не кликается |
| `mine` | фон `--grad`, тёмный текст, метка «вы» |

### Форма
Инпуты: фон `--surface-2`, граница `--line`, радиус `--r-sm`, высота 46px, `font-size: 16px`
(иначе iOS зумит при фокусе). Фокус — градиентная рамка. Ошибка — граница `--err` и подпись под полем.

Главная кнопка — фон `--grad`, тёмный текст, 700, высота 50px, радиус `--r-md`.
В состоянии загрузки — спиннер и `disabled`.

### Тосты
Снизу по центру, `--surface-2`, тень `--shadow`, автоскрытие 4 секунды.
Ошибка — левая граница 3px `--err`, успех — `--ok`.

### Баннер деградации
Липкий сверху, фон `rgba(244,63,94,.12)`, граница `--err`, текст 13px. Появляется, когда
Supabase недоступен; исчезает сам при восстановлении связи.

## Адаптив

Мобильный — основной сценарий: люди сканируют QR телефоном.

| Ширина | Раскладка |
|---|---|
| < 640px | карточки в одну колонку, слоты в 3 колонки |
| 640–1023px | карточки в 2 колонки, слоты в 4 колонки |
| ≥ 1024px | карточки в 2 колонки с `max-width: 1040px`, слоты в 6 колонок |

Проверять на **360px** — самый узкий реальный телефон.

`board.html` — отдельный случай: рассчитан на экран или планшет, шрифты крупнее в 1.5 раза,
колонка на доктора.

## Доступность

- Контраст текста к фону не ниже 4.5:1. `--muted` на `--surface` проверен, `--faint` — только
  для неактивных элементов.
- Все интерактивные элементы — настоящие `<button>` с видимым `:focus-visible`.
- Состояние слота не передаётся одним цветом: всегда есть текст или зачёркивание.
- Тач-цели минимум 44×44px.
