## Стек

Чистая статика на GitHub Pages + Supabase (Postgres + REST) как хранилище.
**Ни сборки, ни npm, ни фреймворков.** Файлы открываются двойным кликом и правятся в любом редакторе.

## Что где меняется

Разделение по критерию «кто и как часто это меняет»:

| Что менять | Где | Нужен деплой |
|---|---|---|
| Тексты карточек докторов, стол, вкл/выкл | Админка → БД | Нет |
| Создать нового доктора | Админка или `supabase/seed.sql` | Нет |
| Удалить бронь | Админка → БД | Нет |
| Длина приёма, окно дня, дата | `config.js` | **Да** |
| Фото доктора | `assets/doctors/<id>.jpg` | **Да** |
| Цвета, шрифты, отступы | Токены в `:root` в `assets/styles.css` | **Да** |
| Логика, вёрстка | `assets/app.js`, `*.html` | **Да** |

Деплой = `git push`. GitHub Pages раскатывает сам за 30–60 секунд. Никакой сборки нет.

## Конвенции, которые нельзя нарушать

**Фото доктора — по имени файла.** `assets/doctors/<id>.jpg`, где `<id>` — идентификатор доктора
из БД. Поля `photo` нет нигде: путь вычисляется из id. Формат — **JPEG, квадрат, минимум 400×400**.
Нет файла → рисуется градиентный аватар с инициалами.

**Всё время — МСК.** Время строится через `mskDate()` (см. `assets/app.js`), которая собирает
абсолютный момент из строки с явным смещением `+03:00`. Никогда не полагаться на таймзону устройства.

**Слоты не хранятся в БД.** Сетка вычисляется на клиенте из `config.js` и окна доктора.
В БД лежит только занятость.

**Персональные данные не торчат наружу.** Публичная view `v_occupancy` отдаёт только
`doctor_id, slot_start, kind` — без имён и команд. Имена доступны только через RPC под токеном.
При любых правках схемы это правило проверять первым.

## Типовые задачи

**Сменить доктора целиком:** в админке выключить старого, создать нового. Фото —
положить `assets/doctors/<новый-id>.jpg` и запушить. Без фото будет аватар с инициалами.

**Поменять длину приёма:** `SLOT_MINUTES` в `config.js`, запушить.
Делать **до** открытия записи: брони хранят абсолютное время и при смене сетки станут `off-grid`
(показываются отдельной строкой, не пропадают, но занять их нельзя).

**Закрыть запись:** выключить «Принимает» у всех докторов в админке. Отдельного стоп-крана нет.

**Пересоздать базу с нуля:** прогнать `supabase/schema.sql`, затем `supabase/seed.sql`
в SQL-редакторе Supabase. Оба идемпотентны.

## Демо-режим

Параметр `?mock=1` подменяет Supabase на данные в памяти браузера
([assets/mock.js](assets/mock.js)). Нужен, чтобы прощёлкать продукт без настроенного
бэкенда. Без параметра файл не делает ничего — на боевой путь не влияет.
