# Черновые аватары докторов

Нарисованы кодом (SVG), не сгенерированы нейросетью: генератора изображений
под рукой нет. Мотивы — из алиаса и поля «опыт» карточки в БД.

| Файл | Доктор | Что нарисовано | Акцент |
|---|---|---|---|
| `doc-1-sonyboy` | Доктор Sonyboy | кассета (алиас), катушки как узлы графа, ниже — ветвление на три репозитория (мультирепы) | #FED000 |
| `doc-2-ai-bolit` | Доктор AI болит | голова-робот, молния «болит» на лбу, гантель (Unicorn Gym) | #F84D15 |
| `doc-3-trinity` | Доктор Тринити | очки с цифровым дождём (Матрица), три сцепленных кольца — «тринити» | #47BAD5 |

Полярность светлая — как у печатной таблички: чёрный контур на #EAE9E7,
один акцент из фирменной тройки. На тёмной витрине смотреть не проверял.

`.svg` — исходник, правится в любом редакторе и масштабируется без потерь.
`.png` — 1024×1024, отрендерены из `_render.html` браузером.
`_render.html` — страница со всеми тремя, из неё снимаются PNG.

в CLAUDE.md: он про изображение лица, иллюстрация под запрет не попадает,
